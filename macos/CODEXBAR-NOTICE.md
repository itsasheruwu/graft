# CodexBar attribution

Graft's optional Auto-use Codex resets tweak adapts the reset-credit wire contract,
five-minute expiry policy, and credential claim parsing from CodexBar:
https://github.com/steipete/CodexBar (local source inspected 2026-10-05).
